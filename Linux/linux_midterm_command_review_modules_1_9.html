Linux Midterm Command Review

NDG Linux Essentials — Modules 1–9 Command and Concept Reference

Review Focus: Know what each command does, recognize common options, and understand how commands are used with files, directories, permissions, help tools, variables, redirection, and basic Linux system information.

Note: Module 4 is included as key open source and licensing terms because it is concept-heavy rather than command-heavy.

Module 1: Introduction to Linux

Linux

The operating system kernel that manages hardware, memory, processes, devices, and system resources.

GNU/Linux

A full operating system environment that combines the Linux kernel with GNU tools and other software.

Kernel

The core part of the operating system that manages communication between software and hardware.

Linux distribution

A complete Linux-based operating system that includes the kernel, tools, applications, and package management.

Linux Mint

A beginner-friendly Linux distribution with a graphical desktop and terminal access.

GUI

Graphical User Interface; uses windows, menus, icons, and a mouse.

CLI

Command Line Interface; uses typed commands in a terminal.

whoami

Shows the current logged-in username.

pwd

Prints the current working directory.

ls

Lists files and folders in the current directory.

hostname

Shows the computer or system name.

date

Displays the current system date and time.

cat /etc/os-release

Displays Linux distribution information.

uname -r

Shows the Linux kernel version.

Module 2: Operating Systems and Linux Servers

Operating system

Software that manages hardware, applications, files, users, and system resources.

Windows

Common desktop operating system used in home, school, and business environments.

macOS

Apple operating system based on UNIX concepts and designed for Apple hardware.

Linux server

A Linux system that provides services such as websites, databases, file sharing, cloud systems, or security tools.

Red Hat family

Linux distribution family commonly used in enterprise server environments.

Debian family

Linux distribution family that includes Debian, Ubuntu, and Linux Mint.

SUSE family

Linux distribution family often used in professional and enterprise environments.

cat /etc/os-release

Identifies the Linux distribution and release information.

uname -r

Displays the current Linux kernel version.

ip addr

Shows network interface and IP address information.

ip -br a

Shows brief network interface and IP address information.

df -h

Shows disk space usage in human-readable format.

free -h

Shows memory usage in human-readable format.

sudo apt update

Updates package information on Debian, Ubuntu, and Linux Mint systems.

Module 3: Working in Linux

date

Shows the current system date and time.

cat /etc/machine-id

Displays the unique machine ID for the Linux system.

pwd

Shows the current working directory.

whoami

Shows the current logged-in user.

ls

Lists files and folders in the current directory.

nano notes.txt

Opens or creates a text file named notes.txt in the nano editor.

sudo apt update

Refreshes available software package information.

apt list --installed | head

Lists installed packages and displays only the first several lines.

sudo ufw status

Checks the status of the uncomplicated firewall.

apt

Debian-based package management tool used by Linux Mint, Ubuntu, and Debian.

apt-get

Older Debian-based package management command still commonly seen in documentation.

dpkg

Lower-level Debian package tool used to install, remove, and inspect packages.

rpm

Package format and tool used by Red Hat-based Linux systems.

dnf

Package manager commonly used by Fedora and other Red Hat-based systems.

root

The most powerful administrative account on a Linux system.

Virtual machine

A complete guest operating system running on a host computer through a hypervisor.

Container

A lightweight isolated application environment; commonly associated with Docker and Kubernetes.

Hypervisor

Software that manages virtual machines on a host system.

Module 4: Open Source Software and Licensing

Open source software

Software where the source code can be viewed, studied, modified, and often shared under license rules.

Source code

Human-readable instructions written by programmers to create software.

Compiled software

Software translated into a form the computer can run.

Software license

Defines what users are allowed to do with software.

EULA

End User License Agreement; a legal agreement users accept before using software.

GPL

GNU General Public License; an open source license with copyleft requirements.

GPLv2

Version 2 of the GNU General Public License.

Copyleft

Requires modified redistributed versions to remain under the same license terms.

Permissive license

Open source license with fewer restrictions than copyleft licenses.

FOSS

Free and Open Source Software.

FLOSS

Free/Libre/Open Source Software.

FSF

Free Software Foundation; promotes software freedom and copyleft licensing.

OSI

Open Source Initiative; supports and approves open source licenses.

Creative Commons

Licenses often used for creative works such as images, videos, documents, and learning materials.

CC BY

Creative Commons license requiring attribution to the creator.

CC BY-SA

Requires attribution and sharing modified versions under the same license.

CC BY-ND

Allows sharing with attribution but does not allow modified versions.

CC BY-NC

Allows use with attribution but not for commercial purposes.

CC BY-NC-ND

Requires attribution, does not allow commercial use, and does not allow modified versions.

CC0

Public domain style license with no rights reserved.

Module 5: Command Line Skills

student@linuxmint:~$

Example terminal prompt showing username, hostname, current directory, and normal user prompt.

command [options] [arguments]

Common Linux command pattern: command first, options modify behavior, arguments tell the command what to act on.

pwd

Shows the current working directory.

ls

Lists files and directories.

date

Displays the current system date and time.

cal

Displays a calendar.

whoami

Shows the current logged-in username.

hostname

Shows the computer or system name.

clear

Clears the terminal screen.

ls -l

Lists files in long format.

ls -a

Shows all files, including hidden files.

ls -h

Shows sizes in human-readable format when used with long listing options.

ls -lh

Shows long listing details with human-readable file sizes.

ls -lah

Shows hidden files, long format, and human-readable sizes.

ls -r

Reverses the listing order.

ls -lr

Shows long format in reverse order.

ls /etc

Lists the contents of the /etc directory.

ls -l /etc

Lists /etc in long format.

ls /etc /bin

Lists multiple directories.

history

Displays previously typed commands.

history 5

Shows the most recent five commands.

history | tail -n 10

Shows the last ten commands from history.

!!

Runs the previous command again.

!ls

Runs the most recent command that started with ls.

!15

Runs command number 15 from command history.

course="Linux Essentials"

Creates a shell variable named course. Do not use spaces around the equals sign.

echo $course

Displays the value stored in the course variable.

echo $HOME

Displays the current user's home directory path.

echo $PATH

Displays where the shell searches for commands.

env

Displays environment variables.

env | grep HOME

Searches environment variables for HOME.

type cd

Shows whether cd is a shell built-in.

type ls

Shows how the shell identifies the ls command.

type echo

Shows how the shell identifies echo.

type -a echo

Shows all matches for echo, including built-ins and external commands.

which ls

Shows the path to the ls executable.

which bash

Shows the path to bash.

which python3

Shows the path to python3 if installed.

alias

Displays aliases in the current shell session.

alias ll='ls -alF'

Creates a temporary alias named ll.

ll

Runs the command assigned to the ll alias.

type ll

Verifies whether ll is an alias.

unalias ll

Removes the ll alias from the current shell session.

nano ~/.bashrc

Opens the bash configuration file where permanent aliases can be added.

source ~/.bashrc

Reloads the bash configuration file.

echo "My home directory is $HOME"

Double quotes allow variable expansion.

echo 'My home directory is $HOME'

Single quotes print text exactly as typed.

echo "The cost is \$100"

Backslash prevents the dollar sign from being treated as a variable.

echo "Today is $(date)"

Runs the date command inside another command.

pwd; ls; date

Runs commands one after another.

ls /etc && echo "The /etc directory exists."

Runs the second command only if the first succeeds.

ls /notreal || echo "That directory does not exist."

Runs the second command only if the first fails.

Module 7: Navigating the Linux Filesystem

/

The root directory; the top of the Linux filesystem.

~

Shortcut for the current user's home directory.

.

Represents the current directory.

..

Represents the parent directory.

pwd

Prints the current working directory.

cd

Returns to the current user's home directory.

cd ~

Moves to the current user's home directory.

cd /

Moves to the root directory.

cd ..

Moves up one directory level.

cd Documents

Moves into Documents using a relative path.

cd Downloads

Moves into Downloads using a relative path.

cd /home/$USER/Documents

Moves into Documents using an absolute path.

cd ./Downloads

Moves into Downloads using a path from the current directory.

cd ../Pictures

Moves up one level, then into Pictures.

ls /

Lists the root directory.

ls ~

Lists the current user's home directory.

ls /home

Lists user home folders.

ls /var/log

Lists system log directory contents.

ls -a

Shows all files, including hidden files.

ls -l

Shows long listing details such as permissions, owner, size, and timestamp.

ls -lh

Shows long listing details with human-readable file sizes.

ls -ld

Shows information about the directory itself, not its contents.

ls -R

Lists files recursively through subdirectories.

ls -t

Sorts files by modification time.

ls -S

Sorts files by size.

ls -r

Reverses listing order.

ls -la

Shows hidden files in long format.

ls -lS

Shows long format sorted by size.

ls -lSh

Shows long format sorted by size with human-readable sizes.

ls -lt

Shows long format sorted by modification time.

ls -ltr

Shows long format sorted by time in reverse order.

mkdir LinuxPractice

Creates a directory named LinuxPractice.

mkdir -p LinuxPractice/Module7/Notes

Creates a full directory path, including parent directories if needed.

mkdir -p LinuxPractice/Module7/Screenshots

Creates a screenshots folder path inside the Module7 directory.

ls -ld ~

Shows details about the home directory itself.

ls -l /dev | head

Shows the first few long-listing entries in /dev.

d

In ls -l output, indicates a directory.

-

In ls -l output, indicates a regular file.

l

In ls -l output, indicates a symbolic link.

b or c

In ls -l output, indicates a device file.

sudo apt install tree

Installs the tree command.

tree /home

Displays the /home directory in a tree-style layout.

tree -L 2 /

Displays the root directory as a tree limited to two levels.

Cumulative File, Permission, and Redirection Commands

script cli_M1-7_lastname.txt

Starts recording the terminal session into a script file.

EXIT

Stops the script session when used after script is running.

touch file1.txt

Creates an empty file or updates its timestamp.

echo "hello" > file2.txt

Writes text to a file, replacing existing contents.

printf "test\nline2\n" > file3.txt

Creates a file with formatted text and line breaks.

nano file5.txt

Opens or creates file5.txt in the nano text editor.

cat file3.txt

Displays the full contents of a file.

head -n 1 file3.txt

Shows the first line of a file.

tail -n 1 file3.txt

Shows the last line of a file.

wc file3.txt

Counts lines, words, and characters in a file.

mkdir backup

Creates a directory named backup.

cp file1.txt file4.txt

Copies one file to another file.

cp *.txt backup/

Copies all .txt files into the backup directory.

ls backup/

Lists the contents of the backup directory.

chmod 600 file1.txt

Allows only the owner to read and write the file.

chmod u+x file2.txt

Adds execute permission for the owner.

chmod g-w file3.txt

Removes write permission from the group.

sudo chown $USER:$USER file4.txt

Changes the file owner and group to the current user.

echo -e "line1\nline2\nline3" > data.txt

Creates data.txt with multiple lines of text.

echo "line4" >> data.txt

Appends line4 to the end of data.txt.

wc -l data.txt

Counts the number of lines in data.txt.

grep "line" data.txt

Searches data.txt for lines containing line.

cat data.txt | sort | uniq

Displays, sorts, and removes duplicate lines.

ls nofile.txt > output.txt 2> error.txt

Sends normal output to one file and error messages to another file.

>

Redirects output to a file and overwrites the file.

>>

Appends output to the end of a file.

2>

Redirects error messages to a file.

|

Sends the output of one command into another command.

date > module1-7_practice_log.txt

Writes the current date into a practice log file.

cat /etc/machine-id >> module1-7_practice_log.txt

Appends the machine ID to the practice log file.
