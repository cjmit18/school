A **Discrete variable** is a **quantitative variable**  that can be counted or isn't infinite in nature.

A **Continuous Variable** is a **quantitative variable** is an uncountable number that is either infinite or may take on any possible value between two values.

A **Histogram** is constructed by drawing rectangles for each class of data.
- The height of each rectangle is the frequency of the class.
- The Width if each rectangle is the same, and the rectangles touch each other.

A Class is a way to sort discreet or continuous data by splitting them into groups, IE: 25-35, 36 - 45.

- A **Closed Class** is a class with specific inclusive requirements when sorting data such as 25-35
- An **Open class** is a class when the class doesn't have an **Upper** or **Lower** limit such as 25 and older or 15 and under.
- The **Class Width** is the difference between consecutive lower class limits
- **Class Width = largest data value - smallest data value / number of classes**
	 - Round the value to a convenient number. 

**Uniform Distribution** - frequency of each value is spread out evenly across the values of the variable.

**Bell Shaped Distribution** - Highest frequency occurs in the middle and tail of on the right and the left of the center.

**Right Skewed** - Highest on the left tails on the right

**Left Skewed** - Tail is on the left Highest is on the right
