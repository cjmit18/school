When looking at a **Distribution of Data** consider **Three Characteristics** of the data:
1. Shape
2. Center
3. Spread
The **Center and Spread** are **Numerical Summaries** of the Data. The "**Center**" of a data set is more commonly called an "**Average**"
The Most appropriate measure of center and spread used to describe a set of data depends on the distributions shape.
When you know the **Three Characteristics** then you can figure out the outliers.

The **arithmetic mean** of a variable is computed by adding all the values of the variable in the data set and dividing by the number of observations.

The **population arithmetic mean**, $\mu$ (pronounced “mew”), is a parameter that is computed using data from all the individuals in a population.

The **sample arithmetic mean,**  $\bar{x}$ (pronounced “x-bar”), is statistic that is computed using data from individuals in a sample.

**Population Mean**:
If $x_1,x_2 \cdots x_N$ are the N observations of a variable from a population, then the population mean, is $\mu$

Essentially, to find the mean of a set of data (whether the population or sample), add up all the observations and divide by the number of observations.

The **Median** of a variable is the value that lies in the middle of the data when arranged in ascending order 

1.  Arrange data in ascending order
2. Determine the number of observations
3. Determine the observation in the middle of the data set 
- If the number of observations is even then the median is the mean of the two middle observations in the data set. That is, the median is the mean of the observations that lie in the  $\frac{n+1}{2}$ position.
- If the number of observations is even, then the median is the mean of the two middle of the data set. That is, the median is the mean of the observations that lie in the $\frac{n}{2}$ position and the $\frac{n}{2} + 1$ position

When something is **Resistant** if values that are extreme relative to the data do not affect its value substantially.

| Sysmmetric         | Mean roughly equal to median              |

The **Mode** of a variable is the observation of the variable that occurs frequently in the data set.
- To compute the mode , tally the number of observations that occur for each data value
- The data value that occurs most often is the mode
- If no observation occurs more than once, we say that the data has **No Mode**
- A set of data can have no mode, one mode, or more than one mode

A data set can have more than one mode. (Single modal, Bi modal, Multi modal)![[ef62bbe23f533fd17657f981926a7dba.avif]]
