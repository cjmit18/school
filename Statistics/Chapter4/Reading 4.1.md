**Bivariate data** is data in which two variables are measured on an individual.

The **Response Variable(Dependent)** is the variable whose value can be explained by the value of the explanatory (independent)  variable

**A Scatter diagram** is a graph that shows the relationship between two quantitative variables measured on the same individual. Each individual in the data set is represented by a point in the scatter diagram. The explanatory variable is plotted on the horizontal axis and the response variable is plotted on the vertical axis 

**Positively Associated** variables increase at the same rate

**Negatively Associated** if one increases the other decreases (inverse relationship)

The **Linear correlation coefficient** is a measure of strength and direction of the linear relation between two quantitative variables.
