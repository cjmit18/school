The internet has made a massive impact and has fundamentally changed systems design and architecture. Internet-based architecture is based off of systems that operate over the internet, cloud computing allows for more compatibility through usage of the internet as a platform and web 2.0 allows for more collaborative work that wasn't available before. 

In house e-commerce architecture allows for complete control and flexibility as compared to a service provider but need an upfront investment cost while a service prover is typically more cost effective and is a lot more simple and straightforward to get started.

Online processing is done in real-time, its reliable. can handle multiple users or transactions at one time, fast response times and dynamic interactions. Batch processing allows for scheduling, handling larger data sets, efficient resource utilization, delayed output and error handling and stability.

Hierarchical networks operate by assigning systems lower down the chain with lower and lower network permissions while the highest has control of the entire network.
Bus networks have a single communication path that connects to the main server.
A ring network is a circular layout that allows data flow in one direction with both ends connected in order to reduce the amount of data collisions 
A star network offers enhanced reliability and performance due to being connected to a single switch  that manages the network 
A mesh network works by allowing each node to connect with other nodes rather than just a single link to a switch or to the next device over

A router connects networks and determines the most efficient data path in which to send the data down.
A gateway is when using a router or any network routing device to connect a larger dissimilar network.
A proxy server allows internet for internal LAN users so they can use the internet 

Standards allow for interconnectivity between systems and provides a framework for generational improvements using current and future technologies 

NFC allows wireless data transmission using radio waves  and Bluetooth low power wireless communication
