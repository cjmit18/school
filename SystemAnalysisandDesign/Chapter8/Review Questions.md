Explain the primary, super, candidate, foreign, and secondary keys.
A primary key is a field or fields that identifies a member of an entity, a super key is a set of one or more columns that can uniquely identify a record in a table. A candidate key is a field that could serve as a primary key. A foreign key is a field in one table that must match a primary key value in another table. A secondary key is a field ore combination of that can be used to access or retrieve records

How are codes used in data design?
Codes are used to increase efficiency and interpretation and decrease the chance of data input errors. Codes allow for uniqueness and are able to subclassify things within themselves as well as allowing clear meaning and increased scalability due to the nature of codes.
