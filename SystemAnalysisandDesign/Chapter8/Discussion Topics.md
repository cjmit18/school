2. Many large organizations have had their database system hacked and customer data stolen. How should the database’s security differ from the rest of the system? Does it make a difference for web-based data designs? If so, how?

	Permissions should be setup with subschemas so that the database access is on a as needed basis with read only permissions  so that customer data isn't manipulated or view by people who shouldn't be. It does make a difference with web based design because information being transmitted over the internet is more suspectable to intrusion.
